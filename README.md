# 高原观鸟

青藏高原鸟类识别算法与科普智能体展示网站。

公开网址：https://sun04761-sudo.github.io/plateau-bird-observatory/

本站为静态中文演示站，托管于 GitHub Pages，不需要本地开发服务器。

- 自然摄影首屏，尊重减少动态效果设置。
- 黑颈鹤双个体十部位观察，采用原片坐标。
- 热区为交互示意；问答为有资料依据的预设内容。
- 暂未接入实时识别或在线检索。

照片与界面资料来自项目已有素材，图片署名见页面；图片版权归原作者所有。未为第三方素材授予额外许可。

维护：本地 React + TypeScript + Vite 项目执行 `pnpm run build`，然后运行 `python work/package_pages.py` 生成发布目录，上传目录内文件覆盖本站即可。
